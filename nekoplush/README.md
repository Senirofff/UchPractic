# Neko Plush

Простое учебное приложение на React и Vite: пять карточек плюшевых игрушек с отдельными счётчиками.

## Запуск в VS Code

1. Откройте папку проекта в VS Code.
2. Откройте «Терминал → Создать терминал».
3. Выполните `npm install`, затем `npm run dev`.
4. Откройте адрес, который появится в терминале.

Нужен Node.js 20.19+ или 22.12+ (для соответствующих веток; новые версии тоже подходят).
Остановка сервера: Ctrl+C. Сборка: `npm run build`.

## Структура

- `src/App.jsx` — массив из пяти товаров и вывод карточек через `map`. Здесь меняются названия, цены и пути к фото. Цены указаны для примера.
- `src/components/ProductCard.jsx` — название, цена и изображение приходят через props. Количество хранится в `useState(0)` и увеличивается кнопкой на один.
- `src/styles.css` — стили и адаптивная сетка.
- `public/images` — фотографии товаров. Для нового фото укажите, например, `image: '/images/photo.png'` в массиве товаров.

Счётчики сбрасываются при обновлении страницы.
